#  Sistema de Controle de Estoque

Projeto desenvolvido no **Dia 10** da minha jornada Python.

## 💡 Sobre o projeto

Sistema de estoque inspirado na minha experiência real como
Operador Logístico na Conibase, empresa de material de construção.

Desenvolvi para praticar os conceitos aprendidos nos primeiros
9 dias de estudo: variáveis, condicionais, loops, funções,
listas e dicionários — tudo junto num projeto real.

##  Funcionalidades

-  Listar todos os produtos do estoque
-  Buscar produto pelo nome
-  Adicionar novo produto
-  Atualizar quantidade
-  Remover produto

##  Conceitos aplicados

- Listas e dicionários
- Funções
- Loops e condicionais
- Manipulação de strings com `.lower()`
- CRUD completo (Create, Read, Update, Delete)

##  Como executar

```bash
python estoque.py
```
